# SEO Specialist & Authority Builder

Use this skill when users need help with search engine optimization, E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness) evaluation, content authority building, or improving website visibility.

## Core Expertise

### 1. E-E-A-T Signal Optimization
E-E-A-T represents Google's quality evaluation framework across four dimensions:

**Experience Signals:**
- First-hand experience indicators (e.g., "I tested", "In my practice")
- Case studies with real-world outcomes
- Original research and data collection
- Product usage testimonials and reviews
- Behind-the-scenes documentation
- Process photos and videos
- Time-stamped content showing long-term involvement

**Expertise Signals:**
- Author credentials and professional background
- Educational qualifications relevant to topic
- Technical depth and accuracy of content
- Industry-specific terminology usage
- Citations from authoritative sources
- Demonstration of specialized knowledge
- Content complexity appropriate for topic

**Authoritativeness Signals:**
- External citations and backlinks from authority sites
- Brand mentions across the web
- Industry awards and recognition
- Speaking engagements and conference presentations
- Published books or research papers
- Guest posts on authoritative platforms
- Social proof and follower engagement

**Trustworthiness Signals:**
- Contact information clearly displayed
- Comprehensive privacy policy
- SSL certificate (HTTPS)
- Customer testimonials and reviews
- Transparent about business practices
- Clear editorial policies
- Fact-checking processes
- Regular content updates
- Professional website design

### 2. Technical SEO Fundamentals

**Site Architecture:**
- Logical URL structure (e.g., `/category/subcategory/page`)
- Proper use of canonical tags
- XML sitemap generation and submission
- Robots.txt optimization
- Mobile-first responsive design
- Page speed optimization (Core Web Vitals)
- Internal linking strategy
- Breadcrumb navigation

**On-Page Optimization:**
- Title tags (50-60 characters, keyword-focused)
- Meta descriptions (150-160 characters, compelling CTAs)
- Header hierarchy (H1 → H2 → H3)
- Alt text for images (descriptive, includes keywords)
- Schema markup implementation
- Open Graph and Twitter Cards
- Keyword placement in first 100 words
- LSI (Latent Semantic Indexing) keywords

**Performance:**
- Core Web Vitals monitoring (LCP, FID, CLS)
- Image optimization (WebP format, lazy loading)
- Browser caching strategies
- CDN implementation
- Minification of CSS/JS
- Server response time optimization
- Eliminate render-blocking resources

## Red Flags & SEO Mistakes to Avoid

**Black-Hat Techniques (Never Use):**
- ❌ Keyword stuffing
- ❌ Buying backlinks
- ❌ Hidden text or links
- ❌ Cloaking (showing different content to search engines)
- ❌ Duplicate content across domains
- ❌ Article spinning or low-quality content
- ❌ Link farms or PBNs
- ❌ Automated content generation without review

**Common Mistakes:**
- Thin content (under 300 words)
- Ignoring mobile optimization
- Slow page load speeds
- Broken links and 404 errors
- Missing alt text on images
- Duplicate title tags and meta descriptions
- No internal linking strategy
- Ignoring Search Console errors
- Not updating old content
- Overlooking local SEO (for local businesses)

```php
<?php
// app/Console/Commands/GenerateSitemap.php

namespace App\Console\Commands;

use Illuminate\Console\Command;
use Spatie\Sitemap\Sitemap;
use Spatie\Sitemap\Tags\Url;

class GenerateSitemap extends Command
{
    protected $signature = 'sitemap:generate';
    protected $description = 'Generate XML sitemap for SEO';

    public function handle()
    {
        $sitemap = Sitemap::create();

        // Homepage
        $sitemap->add(Url::create('/')
            ->setLastModificationDate(now())
            ->setChangeFrequency(Url::CHANGE_FREQUENCY_WEEKLY)
            ->setPriority(1.0));

        // Features pages
        foreach (['invoicing', 'expenses', 'vat-declaration', 'reports'] as $feature) {
            $sitemap->add(Url::create("/features/{$feature}")
                ->setLastModificationDate(now())
                ->setChangeFrequency(Url::CHANGE_FREQUENCY_MONTHLY)
                ->setPriority(0.8));
        }

        // Blog posts
        BlogPost::published()->each(function ($post) use ($sitemap) {
            $sitemap->add(Url::create(route('blog.show', $post))
                ->setLastModificationDate($post->updated_at)
                ->setChangeFrequency(Url::CHANGE_FREQUENCY_MONTHLY)
                ->setPriority(0.7));
        });

        // Help articles
        HelpArticle::published()->each(function ($article) use ($sitemap) {
            $sitemap->add(Url::create(route('help.show', $article))
                ->setLastModificationDate($article->updated_at)
                ->setChangeFrequency(Url::CHANGE_FREQUENCY_MONTHLY)
                ->setPriority(0.6));
        });

        $sitemap->writeToFile(public_path('sitemap.xml'));

        $this->info('Sitemap generated successfully!');
    }
}
```

```php
// Implement canonical tags
public function generateCanonical(Request $request): string
{
    $canonical = $request->url();

    // Remove tracking parameters
    $allowedParams = ['page', 'category'];
    $params = collect($request->query())
        ->only($allowedParams)
        ->toArray();

    if (!empty($params)) {
        $canonical .= '?' . http_build_query($params);
    }

    return $canonical;
}

// Pagination with rel="next" and rel="prev"
public function paginationLinks(LengthAwarePaginator $paginator): array
{
    $links = [];

    if ($paginator->currentPage() > 1) {
        $links['prev'] = $paginator->previousPageUrl();
    }

    if ($paginator->hasMorePages()) {
        $links['next'] = $paginator->nextPageUrl();
    }

    return $links;
}
```

```php
class CompetitorAnalysis
{
    public function analyzeCompetitor(string $competitorUrl): array
    {
        return [
```

**Don't:**

```php
class ContentFreshnessService
{
    public function getStaleContent(int $monthsOld = 12): Collection
    {
        return BlogPost::where('updated_at', '<', now()->subMonths($monthsOld))
            ->where('organic_traffic_30d', '>', 100) // Still getting traffic
            ->orderBy('organic_traffic_30d', 'desc')
            ->get();
    }

    public function suggestUpdates(BlogPost $post): array
    {
        $suggestions = [];

        // Check for outdated year references
        if (preg_match_all('/\b(20\d{2})\b/', $post->content, $matches)) {
            $oldYears = array_filter($matches[1], fn($y) => $y < now()->year);
            if (!empty($oldYears)) {
                $suggestions[] = "Update year references: " . implode(', ', $oldYears);
            }
        }

        // Check for outdated Dutch tax rates
        if (str_contains($post->content, '21%') && $post->category === 'btw') {
            $suggestions[] = "Verify BTW rates are current for " . now()->year;
        }

        return $suggestions;
    }
}
```

**Rationale:**
Google favors fresh, up-to-date content. Regular updates signal that your site is actively maintained.

## Anti-Patterns

### Anti-Pattern 1: Keyword Stuffing

**The Problem:**
```html
<!-- ❌ BAD -->
<h1>Boekhouding Software - Beste Boekhouding Software voor Boekhouding</h1>
<p>
    Onze boekhouding software is de beste boekhouding software voor
    boekhouding. Als je boekhouding software zoekt, is onze boekhouding
    software de boekhouding software die je nodig hebt.
</p>
```

**Why It's Wrong:**
- Unnatural reading experience
- Google penalizes keyword stuffing
- Damages user trust and credibility

**The Fix:**
```html
<!-- ✅ GOOD -->
<h1>Eenvoudige Boekhoudoftware voor ZZP'ers</h1>
<p>
    Onze software helpt je om je administratie bij te houden zonder
    boekhouding-kennis. Ideaal voor zelfstandigen die tijd willen besparen.
</p>
```

**Impact:**
Keyword stuffing can result in manual penalties or algorithmic devaluation.

### Anti-Pattern 2: Thin Content

**The Problem:**
```markdown
## BTW Aangifte Doen

BTW aangifte is belangrijk. Je moet het elk kwartaal doen.
Gebruik onze software om BTW aangifte te doen.

(Total: 87 words)
```

**Why It's Wrong:**

- Google considers it "thin content"

**The Fix:**

```markdown
Elk kwartaal moet je als ZZP'er BTW-aangifte doen bij de Belastingdienst.

De deadlines voor 2025:

- Q2: 1 april t/m 30 juni → Aangifte vóór 31 juli
...

### Welke gegevens heb je nodig?

Voor je BTW-aangifte verzamel je:
1. Alle verzonden facturen (omzet)
2. Alle ontvangen facturen (inkopen)
3. Bankafschriften ter controle
...

(Total: 2000+ words with actionable steps)
```

**Impact:**
Comprehensive content ranks better and provides more value to users.

### Anti-Pattern 3: Ignoring Mobile Optimization

**The Problem:**
```css
/* ❌ BAD - Fixed desktop widths */
.content {
    width: 1200px;
    font-size: 14px;
}

.sidebar {
    width: 300px;
    float: right;
}
```

```css
        float: right;
    }
}
```

**Impact:**
Mobile optimization is non-negotiable for modern SEO.

```javascript
// Progressive loading with Intersection Observer
const lazyImages = document.querySelectorAll('img.lazy-load');
const imageObserver = new IntersectionObserver((entries, observer) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            const img = entry.target;
            img.src = img.dataset.src;
            img.classList.remove('lazy-load');
            observer.unobserve(img);
        }
    });
});

lazyImages.forEach(img => imageObserver.observe(img));
```

## Security Considerations

### Security Risk 1: SEO Spam Injection

**Vulnerability:**
User-generated content or compromised CMS could inject spam links

**Attack Vector:**
```php
// Malicious comment injection
$comment = '<a href="https://spam-site.com">legitimate text</a>';
```

**Mitigation:**
```php
// Sanitize all user input
use HTMLPurifier;

class ContentSanitizer
{
    public function sanitize(string $html): string
    {
        $config = HTMLPurifier_Config::createDefault();
        $config->set('HTML.Allowed', 'p,br,strong,em,ul,ol,li');
        $config->set('HTML.Nofollow', true); // Add rel="nofollow" to links

        $purifier = new HTMLPurifier($config);
        return $purifier->purify($html);
    }
}

// Add nofollow to external links
public function addNofollowToExternalLinks(string $html): string
{
    $doc = new DOMDocument();
    @$doc->loadHTML($html, LIBXML_HTML_NOIMPLIED | LIBXML_HTML_NODEFDTD);

    foreach ($doc->getElementsByTagName('a') as $link) {
        $href = $link->getAttribute('href');

        // External link detection
        if (!str_starts_with($href, config('app.url'))) {
            $rel = $link->getAttribute('rel');
            $link->setAttribute('rel', trim($rel . ' nofollow noopener'));
        }
    }

    return $doc->saveHTML();
}
```

**Validation:**
- [ ] All user input sanitized
- [ ] External links have rel="nofollow noopener"
- [ ] Regular security scans for injected content
- [ ] Monitor Search Console for spam signals

### Security Risk 2: Negative SEO Attacks

**Vulnerability:**
Competitors could build spammy backlinks to harm your rankings

**Detection:**
```php
class BacklinkMonitor
{
    public function detectSuspiciousBacklinks(): Collection
    {
        // Integrate with Ahrefs/SEMrush API
        $backlinks = $this->fetchBacklinks();

        return $backlinks->filter(function ($link) {
            return $link->domain_rating < 20 // Low quality domain
                || $link->is_gambling_site
                || $link->is_adult_content
                || str_contains($link->anchor_text, 'viagra'); // Spam keywords
        });
    }

    public function disavowSpammyLinks(Collection $links): void
    {
        $disavowFile = $links->map(fn($link) => "domain:{$link->domain}")->join("\n");

        Storage::put('disavow.txt', $disavowFile);

        // Instructions for manual upload to Search Console
        Log::info('Disavow file generated. Upload to Search Console manually.');
    }
}
```

**Mitigation:**
- Monitor backlink profile weekly
- Use Google Disavow Tool for toxic links
- Set up alerts for sudden backlink spikes
- Maintain strong positive backlink profile
