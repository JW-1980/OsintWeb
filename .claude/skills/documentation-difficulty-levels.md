# Documentation Difficulty Levels Expert

Use this skill when users need help creating educational content, help documentation, knowledge base articles, or website content written at 3 different difficulty levels for different audience knowledge levels.

## When to Use

- Writing help documentation for different user expertise levels
- Creating knowledge base articles for a website
- Developing educational content about bookkeeping, tax, or business topics
- Writing "How it works" explanations for non-technical users
- Creating FAQ content that serves both beginners and experts
- Developing training materials at multiple levels
- Writing feature documentation for different audiences

## The 3 Difficulty Levels

### Overview: CEFR/ERK Taalniveaus

The documentation levels align with the **Common European Framework of Reference for Languages (CEFR)**, known in Dutch as **Europees Referentiekader (ERK)**:

| Level | Dutch Name | CEFR/ERK | Category | Description |
|-------|------------|----------|----------|-------------|
| **Level 1** | Eenvoudig | **A1/A2** | Basisgebruiker | Simple words and sentences about familiar topics |
| **Level 2** | Gevorderd | **B1/B2** | Zelfstandige gebruiker | Can understand main points, produce detailed text |
| **Level 3** | Expert | **C1/C2** | Vaardige gebruiker | Complex texts, nuanced expression, professional use |

### CEFR Level Characteristics

| CEFR | Dutch Term | Vocabulary | Sentence Complexity | Typical Audience |
|------|------------|------------|---------------------|------------------|
| **A1** | Doorbraak | ~1,500 words | Very short, simple | Complete beginners |
| **A2** | Tussenstap | ~3,000 words | Short, everyday | Basic users |
| **B1** | Drempel | ~5,000 words | Medium, can express opinions | MBO level |
| **B2** | Uitzicht | ~8,000 words | Complex main points | HBO level |
| **C1** | Effectief | ~12,000 words | Long, implicit meaning | University level |
| **C2** | Beheersing | ~15,000+ words | Any complexity, nuanced | Native/professional |

### Level 1: Beginner (Eenvoudig) — CEFR A1/A2

**Taalniveau:** A1 (Doorbraak) / A2 (Tussenstap) — Basisgebruiker

**Target Audience:**
- Complete newcomers to the topic
- Small business owners without financial background
- ZZP'ers (freelancers) just starting out
- Non-Dutch speakers learning Dutch business concepts
- Users who prefer simple, clear explanations
- **Anyone with A1/A2 language proficiency**
- Inburgeraars (people doing civic integration)

**CEFR A1/A2 Characteristics:**
- Understands simple words and sentences about familiar topics
- Can introduce themselves and ask basic questions
- Can understand short, simple texts about everyday matters
- Needs slow, clear communication

**Vocabulary Requirements:**
- Use only the **3,000 most common words** in the language (A2 level)
- If a simpler word exists, use it (e.g., "rekening" instead of "factuur")
- Every technical term MUST be explained in plain language
- Avoid compound words where possible (Dutch: use "BTW" not "omzetbelasting")
- Use concrete words, avoid abstract concepts

**Writing Characteristics:**
| Aspect | Guidelines |
|--------|------------|
| **CEFR Level** | A1/A2 (Basisgebruiker) |
| **Vocabulary** | ~3,000 words - everyday words, no jargon |
| **Sentence length** | Short (10-15 words max) |
| **Paragraphs** | 2-3 sentences max |
| **Explanations** | Define ALL technical terms in simple words |
| **Analogies** | Use real-world comparisons from daily life |
| **Tone** | Friendly, supportive, encouraging |
| **Assumptions** | Assume zero prior knowledge |
| **Education level** | Groep 8 / VMBO / Inburgering |

**Structure Template:**
```markdown
# [Simple Title - What This Is]

## Wat is [term]? (What is [term]?)
[One-sentence definition in plain language]

## Waarom is dit belangrijk? (Why does this matter?)
[2-3 sentences explaining the benefit to them personally]

## Hoe werkt het? (How does it work?)
[Step-by-step explanation with numbered list]
1. First, you...
2. Then, you...
3. Finally, you...

## Een voorbeeld (An example)
[Concrete, relatable example from daily life]

## Veelgestelde vragen (FAQ)
- Q: [Simple question]
- A: [Direct answer]
```

**Language Examples (Dutch - Beginner):**
```markdown
❌ BAD: "De fiscale aftrekposten voor ondernemers omvatten de zelfstandigenaftrek, MKB-winstvrijstelling, en startersaftrek."

✅ GOOD: "Als ondernemer mag je minder belasting betalen. Dit heet een aftrekpost. Er zijn drie belangrijke aftrekposten:
1. Zelfstandigenaftrek - Extra korting omdat je voor jezelf werkt
2. MKB-winstvrijstelling - Korting op je winst
3. Startersaftrek - Extra korting als je net begonnen bent"
```

**Power Words for Beginners:**
- Dutch: Eenvoudig, Stap voor stap, Uitgelegd, Wat is, Hoe werkt, Voorbeeld, Tip
- English: Simple, Easy, Step-by-step, Explained, What is, How to, Example, Tip

### Level 2: Intermediate (Gevorderd) — CEFR B1/B2

**Taalniveau:** B1 (Drempel) / B2 (Uitzicht) — Zelfstandige gebruiker

**Target Audience:**
- Users with basic understanding of the topic
- Business owners with 1-5 years experience
- Employees responsible for administration
- Users who understand basics but need deeper knowledge
- Accountants' clients who want to understand their own books
- **Anyone with B1/B2 language proficiency**
- MBO/HBO students and graduates

**CEFR B1/B2 Characteristics:**
- Can understand main points of clear standard text on familiar matters
- Can produce connected text on familiar topics
- Can describe experiences, events, and give reasons for opinions (B1)
- Can understand complex text on concrete and abstract topics (B2)
- Can interact with native speakers without strain (B2)

**Vocabulary Requirements:**
- Use **5,000-8,000 words** vocabulary (B1/B2 level)
- Common industry terms are acceptable (e.g., "factuur", "debiteur", "crediteur")
- Define specialized or uncommon terms on first use
- Can use more precise terminology than Level 1
- Abstract concepts allowed with context

**Writing Characteristics:**
| Aspect | Guidelines |
|--------|------------|
| **CEFR Level** | B1/B2 (Zelfstandige gebruiker) |
| **Vocabulary** | ~5,000-8,000 words - industry terms okay, define uncommon ones |
| **Sentence length** | Medium (15-25 words) |
| **Paragraphs** | 3-5 sentences |
| **Explanations** | Explain "why" and context, not just "what" |
| **Depth** | Include nuances, exceptions, edge cases |
| **Tone** | Informative, practical, solution-focused |
| **Assumptions** | Knows basics, needs practical application |
| **Education level** | MBO / HAVO / VWO / HBO |

### Level 3: Expert (Expert) — CEFR C1/C2

**Taalniveau:** C1 (Effectief) / C2 (Beheersing) — Vaardige gebruiker

**Target Audience:**
- Financial professionals and accountants
- Experienced business owners (5+ years)
- Users researching specific complex scenarios
- Power users wanting comprehensive reference
- People preparing for audits or complex filings
- **Anyone with C1/C2 language proficiency**
- University graduates, professionals, native speakers

**CEFR C1/C2 Characteristics:**
- Can understand long, complex texts including implicit meaning (C1)
- Can express ideas fluently and spontaneously (C1)
- Can use language flexibly for social, academic, and professional purposes (C1)
- Can understand virtually everything heard or read (C2)
- Can summarize information from different sources, reconstructing arguments (C2)
- Can express themselves spontaneously, very fluently, and precisely (C2)

**Vocabulary Requirements:**
- Use **12,000-15,000+ words** vocabulary (C1/C2 level)
- Full technical terminology without simplification
- Industry jargon and specialized terms expected to be understood
- Legal and regulatory language acceptable
- Uncommon words and complex compound terms allowed
- No need to define standard professional terminology

**Writing Characteristics:**
| Aspect | Guidelines |
|--------|------------|
| **CEFR Level** | C1/C2 (Vaardige gebruiker) |
| **Vocabulary** | ~12,000+ words - technical terminology, uncommon words allowed |

| **Paragraphs** | As needed for topic |
| **Explanations** | Technical precision, legal references |
| **Depth** | Complete coverage, edge cases, jurisprudence |
| **Tone** | Professional, authoritative, precise |
| **Assumptions** | Professional knowledge, seeking specific answers |
| **Education level** | HBO / WO (University) / Professional |

## Writing Process

### Step 1: Identify the Topic and Scope
```markdown
Topic: [e.g., "BTW (VAT)"]
Scope: [What aspects to cover]
Target users: [Who will read this]
```

### Step 2: Write Expert Level First
- Gather all technical details, regulations, exceptions
- This becomes your "source of truth"
- Include all references and calculations

### Step 3: Simplify to Intermediate
- Remove highly technical jargon
- Keep practical details and examples
- Add "why" explanations
- Remove legal references (or simplify to footnotes)

### Step 4: Simplify to Beginner
- Use only everyday language
- Focus on "what do I need to do?"
- Add relatable analogies
- Remove nuances (or add as "good to know" boxes)

### Step 5: Cross-link Levels
```markdown
<!-- At end of Beginner article -->
## Meer weten? (Want to know more?)
- [Intermediate: Practical guide to BTW-aangifte]
- [Expert: BTW special cases and exceptions]

<!-- At start of Expert article -->
> **Looking for basics?** See our [Beginner guide to BTW]
```

## Example: BTW at 3 Levels

### Level 1: BTW voor Beginners

# Wat is BTW?

## In het kort
BTW staat voor Belasting Toegevoegde Waarde. Het is een belasting op producten en diensten.

## Hoe werkt het?
Stel je verkoopt iets voor €100. Je rekent daar BTW bovenop. De klant betaalt €121 (€100 + €21 BTW). Die €21 draag je af aan de Belastingdienst.

**Maar:** de BTW die jij betaalt voor je bedrijf, mag je er weer afhalen. Dit heet voorbelasting.

## Een simpel voorbeeld
- Je verkoopt: €1.000 + €210 BTW = €1.210
- Je koopt in: €500 + €105 BTW = €605
- Je draagt af: €210 - €105 = €105

## Wat moet je doen?
1. Zet BTW op je facturen
2. Houd bij wat je ontvangt en betaalt
3. Doe elke periode BTW-aangifte

> **Meer weten?** Lees onze [praktische BTW-gids]

### Level 2: BTW - Praktische Gids

# BTW-aangifte: Praktische Handleiding

## Overzicht
Als ondernemer ben je BTW-plichtig als je omzet boven €20.000 per jaar ligt (kleine ondernemersregeling). Je doet aangifte per kwartaal of maand, afhankelijk van je omzetgrootte.

## De 3 BTW-tarieven

| Tarief | Percentage | Voorbeelden |
|--------|------------|-------------|
| Hoog | 21% | Meeste producten en diensten |
| Laag | 9% | Voedsel, boeken, medicijnen, hotels |
| Nul | 0% | Export, medische diensten, onderwijs |

## BTW-aangifte stap voor stap

### 1. Verzamel je gegevens
- Alle verstuurde facturen (BTW die je moet afdragen)
- Alle ontvangen facturen (BTW die je mag terugvragen)

### 2. Vul de aangifte in
In Boekhouder wordt dit automatisch berekend. De belangrijkste rubrieken:
- 1a: Leveringen binnenland 21%
- 1b: Leveringen binnenland 9%
- 5b: Voorbelasting

### 3. Controleer en verstuur
- Check of het saldo klopt met je boekhouding
- Verstuur via Mijn Belastingdienst
- Betaal of ontvang binnen 2 maanden

## Let op: veelgemaakte fouten
- **Privé-uitgaven:** BTW op privé-aankopen mag je niet aftrekken
- **Geen factuur:** Zonder correcte factuur geen BTW-aftrek
- **Verkeerd tarief:** Check altijd welk tarief van toepassing is

> **Beginnersversie:** [BTW uitgelegd voor starters]
> **Meer detail:** [BTW speciale gevallen en uitzonderingen]

### Level 3: BTW - Technische Referentie

# BTW: Wettelijk Kader en Bijzondere Regelingen

## Wettelijke basis
De omzetbelasting is geregeld in de Wet op de omzetbelasting 1968 (Wet OB 1968), gebaseerd op EU-richtlijn 2006/112/EG (BTW-richtlijn).

## Ondernemerschap (art. 7 Wet OB)
Een ondernemer is ieder die zelfstandig een bedrijf of beroep uitoefent. Let op de volgende criteria:
- Duurzaamheid van de activiteit
- Zelfstandigheid (niet in dienstbetrekking)
- Economische activiteit (ongeacht winstoogmerk)

## Bijzondere regelingen

### Kleine Ondernemersregeling (KOR) - art. 25 Wet OB
Per 1-1-2020 herzien. Voorwaarden:
- Omzet < €20.000 per kalenderjaar
- Vestiging in Nederland
- Geen BTW op facturen, geen recht op voorbelasting
- Vrijwillige keuze, minimaal 3 jaar

### Verleggingsregelingen
| Regeling | Situatie | Grondslag |
|----------|----------|-----------|
| B2B intracommunautair | Levering aan EU-ondernemer | Art. 12 lid 2 |
| Import | Invoer uit niet-EU | Art. 23 |
| Onderaanneming bouw | Bepaalde bouwwerkzaamheden | Art. 12 lid 5 |

### Margeregeling (art. 28b-28i Wet OB)
Voor wederverkopers van gebruikte goederen, kunst, antiek, verzamelobjecten:
- BTW over winstmarge, niet over totaalprijs
- Geen factuur-BTW, dus koper geen aftrek
- Administratieve verplichtingen: gescheiden administratie

## Formele verplichtingen

### Factuurvereisten (art. 35a Wet OB)
Verplichte vermeldingen:
1. Factuurdatum en volgnummer
2. NAW-gegevens leverancier en afnemer
3. BTW-identificatienummer beide partijen (bij B2B)
4. Omschrijving goederen/diensten
5. Maatstaf van heffing per tarief
6. BTW-bedrag per tarief
7. Totaalbedrag

### Bewaartermijn
Fiscale bewaarplicht: 7 jaar (art. 52 AWR)
Onroerend goed gerelateerd: 10 jaar (herzieningstermijn)

## Jurisprudentie
Relevante arresten:
- HR 15 december 2006, BNB 2007/123: ondernemerschap bij holdings
- HvJ EU C-653/11 (Newey): substance over form bij BTW-constructies

## Language & Translation Requirements

### Primary Language: Dutch (Nederlands)
All documentation content is **written in Dutch first**. This is the source content that will be translated to other languages.

### Translation Workflow

```
1. Write content in Dutch (source)
         ↓
2. Review and approve Dutch version
         ↓
3. Translate to target languages
         ↓
4. Review translations for accuracy and tone
```

### Supported Languages

| Language | Code | Priority | Notes |
|----------|------|----------|-------|
| **Dutch** | NL | Primary | Source language, written first |
| **English** | EN | High | International users |
| **German** | DE | Medium | DACH region users |
| **French** | FR | Medium | Belgian/French users |

### Translation Guidelines per Level

**Level 1 (Beginner):**
- Keep vocabulary simple in all languages
- Avoid idioms that don't translate well
- Use universal examples where possible
- Dutch examples can be localized (e.g., BTW → VAT/MwSt)

**Level 2 (Intermediate):**
- Industry terms may differ per country (factuur/invoice/Rechnung)
- Keep legal references neutral or add country-specific notes
- Practical examples should be localized

**Level 3 (Expert):**
- Legal references are country-specific
- May need entirely different versions per country
- Tax and regulatory content requires localization, not just translation

### Implementation Options

#### Option 1: Client-Side Search (Recommended for small docs)

Use a JavaScript library like **Lunr.js** or **Fuse.js**:

```javascript
// Build search index at build time
import Fuse from 'fuse.js';

const searchIndex = new Fuse(documents, {
  keys: ['title', 'content', 'tags'],
  includeMatches: true,
  threshold: 0.3,  // Fuzzy matching tolerance
});

// Search function
function search(query, levelFilter = null) {
  let results = searchIndex.search(query);
  if (levelFilter) {
    results = results.filter(r => r.item.level === levelFilter);
  }
  return results;
}
```

**Pros:** Fast, no server required, works offline
**Cons:** Large index for many documents, initial load time

#### Option 2: Server-Side Search (Laravel)

Use Laravel Scout with Meilisearch or Algolia:

```php
// Documentation model with search
class Documentation extends Model
{
    use Searchable;

    public function toSearchableArray()
    {
        return [
            'id' => $this->id,
            'title' => $this->title,
            'content' => $this->content,
            'level' => $this->level,      // 'beginner', 'intermediate', 'expert'
            'cefr' => $this->cefr,        // 'A1/A2', 'B1/B2', 'C1/C2'
            'topic' => $this->topic,
            'language' => $this->language,
        ];
    }
}

// Search controller
class DocumentationSearchController extends Controller
{
    public function search(Request $request)
    {
        $query = $request->input('q');
        $level = $request->input('level');
        $lang = $request->input('lang', 'nl');

        $results = Documentation::search($query)
            ->when($level, fn($q) => $q->where('level', $level))
            ->where('language', $lang)
            ->get();

        return response()->json($results);
    }
}
```

### Vue Search Component

```vue
<template>
  <div class="doc-search">
    <div class="search-input-wrapper">
      <input
        v-model="query"
        type="search"
        placeholder="Zoeken in documentatie..."
        @input="debouncedSearch"
      />
      <span class="search-icon">🔍</span>
    </div>

    <!-- Level filter -->
    <div class="level-filter" v-if="query">
      <button
        v-for="level in levels"
        :key="level.key"
        :class="{ active: selectedLevel === level.key }"
        @click="filterByLevel(level.key)"
      >
        {{ level.icon }} {{ level.cefr }}
      </button>
    </div>

    <!-- Results -->
    <div class="search-results" v-if="results.length">
      <div
        v-for="result in results"
        :key="result.id"
        class="search-result"
        @click="goToResult(result)"
      >
        <span class="result-level">{{ result.icon }} {{ result.cefr }}</span>
        <h4 v-html="highlight(result.title, query)"></h4>
        <p v-html="highlight(result.excerpt, query)"></p>
      </div>
    </div>

    <!-- No results -->
    <div v-else-if="query && !loading" class="no-results">
      Geen resultaten gevonden voor "{{ query }}"
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue';
import { useDebounceFn } from '@vueuse/core';

const query = ref('');
const results = ref([]);
const selectedLevel = ref(null);
const loading = ref(false);

const levels = [
  { key: 'beginner', cefr: 'A1/A2', icon: '📖' },
  { key: 'intermediate', cefr: 'B1/B2', icon: '📚' },
  { key: 'expert', cefr: 'C1/C2', icon: '🎓' },
];

const search = async () => {
  if (!query.value) {
    results.value = [];
    return;
  }
  loading.value = true;
  const response = await fetch(`/api/docs/search?q=${query.value}&level=${selectedLevel.value || ''}`);
  results.value = await response.json();
  loading.value = false;
};

const debouncedSearch = useDebounceFn(search, 300);

const filterByLevel = (level) => {
  selectedLevel.value = selectedLevel.value === level ? null : level;
  search();
};

const highlight = (text, query) => {
  if (!query) return text;
  const regex = new RegExp(`(${query})`, 'gi');
  return text.replace(regex, '<mark>$1</mark>');
};
</script>
```

### Flutter Search Widget

```dart
class DocSearchWidget extends StatefulWidget {
  @override
  _DocSearchWidgetState createState() => _DocSearchWidgetState();
}

class _DocSearchWidgetState extends State<DocSearchWidget> {
  final TextEditingController _controller = TextEditingController();
  List<DocSearchResult> _results = [];
  String? _levelFilter;

  Future<void> _search(String query) async {
    if (query.isEmpty) {
      setState(() => _results = []);
      return;
    }

    final response = await http.get(
      Uri.parse('/api/docs/search?q=$query&level=${_levelFilter ?? ""}'),
    );

    setState(() {
      _results = (jsonDecode(response.body) as List)
          .map((r) => DocSearchResult.fromJson(r))
          .toList();
    });
  }

  @override
  Widget build(BuildContext context) {
    return Column(
      children: [
        // Search input
        TextField(
          controller: _controller,
          decoration: InputDecoration(
            hintText: 'Zoeken in documentatie...',
            prefixIcon: Icon(Icons.search),
          ),
          onChanged: (value) => _search(value),
        ),

        // Level filter chips
        Wrap(
          children: [
            FilterChip(
              label: Text('📖 A1/A2'),
              selected: _levelFilter == 'beginner',
              onSelected: (selected) {
                setState(() => _levelFilter = selected ? 'beginner' : null);
                _search(_controller.text);
              },
            ),
            // ... more filter chips
          ],
        ),

        // Results list
        Expanded(
          child: ListView.builder(
            itemCount: _results.length,
            itemBuilder: (context, index) {
              final result = _results[index];
              return ListTile(
                leading: Text(result.levelIcon),
                title: Text(result.title),
                subtitle: Text(result.excerpt),
                trailing: Chip(label: Text(result.cefr)),
                onTap: () => _navigateToDoc(result),
              );
            },
          ),
        ),
      ],
    );
  }
}
```
